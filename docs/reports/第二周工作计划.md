# 抖音商城用户行为数据分析 · 第 2 周工作计划

- **项目名称**: 抖音商城用户行为数据分析
- **执行周期**: 第 2 周 (周一 ~ 周五)
- **代码仓库**: https://github.com/xueyingli450-svg/tiktok_user_analysis
- **核心目标**: 从 1035 万条清洗后的纯净数据中，构建包含**基础统计、RFM 价值分群、时序偏好特征、SVD 矩阵隐式语义特征与 Target Encoding 目标编码**的全维度特征体系；完成特征质量检验与相关性筛选，输出标准特征大宽表与《特征工程字典》，为第三周的机器学习预测模型打好输入基石。

---

## 一、 逐日具体工作安排

### 【周一】RFM 用户价值分群模型与画像分析
1. **构建基础 RFM 指标**: 计算用户最近活跃天数间隔 (R) 与总交互频次 (F)，结合行为赋权（购买×4、加购×3、收藏×2、浏览×1）计算综合偏好得分 (M)；
2. **用户四象限分群**: 将 9,700+ 独立用户划分为：高价值 VIP 用户、潜力用户、流失预警用户、沉睡用户；
3. **输出分群画像与分布图**: 绘制 RFM 四象限散点分布图（保存为 `docs/figures/fig8_rfm_user_clusters.png`），记录各分群人数占比与行为特征。

### 【周二】行为时序与自主创新业务特征提取
1. **时序与流转特征 (参考 BST 论文)**: 计算用户相邻点击时间差（Time Delta）与行为跳转转化率（PV -> Cart, Cart -> Buy）；
2. **融入 3 项业务偏好特征构建**:
   - **时段偏好画像**: 计算用户的“晚间黄金时段活跃得分（20:00-23:00）”和“周末集中度”；
   - **比价意向特征**: 结合第一周发现的规律，提取用户“1小时内同一商品高频比价指数”；
   - **加购流失预警**: 提取用户“加购后犹豫未买时长（小时）”；
3. **商品侧特征**: 统计各商品和类目的被浏览总次数、跳失率（高浏览零加购）以及加购转化强力指数。

### 【周三】高阶隐式特征挖掘（SVD 矩阵分解）
1. **构建稀疏交互矩阵**: 使用 `scipy.sparse` 构建“用户-商品”的加权交互稀疏矩阵；
2. **Truncated SVD 降维分解**: 将高维稀疏矩阵降维分解为 **16 维的 User Latent Embedding** 与 **Item Latent Embedding**；
3. **协同偏好度量**: 计算用户隐式向量与目标候选商品的余弦相似度，捕捉未曾显式表达的协同兴趣。

### 【周四】高维类目 Target Encoding 编码与特征矩阵整合
1. **Target Encoding (目标编码)**: 对 3,745 个高维 `item_category` 进行平滑目标编码，替代稀疏 One-Hot，避免维度灾难；
2. **连续特征标准化**: 使用 `StandardScaler` 对数值特征进行标准化缩放；
3. **特征大宽表构建**: 整合周一至周四提取出的全部统计、RFM、时序、创新及 SVD 特征，导出为 `data/processed/user_feature_matrix.parquet`。

### 【周五】特征筛选、特征工程字典编制与第二周周报
1. **特征筛选流水线**:
   - 运行**方差过滤（Variance Threshold）**剔除低区分度特征；
   - 绘制**相关性热力图（Correlation Heatmap）**排查多重共线性（保存至 `docs/figures/fig9_feature_correlation.png`）；
   - 计算**互信息评分（Mutual Information）**评估各特征对购买预测的贡献度排名；
2. **编制《特征工程字典》**: 产出规范文档 `docs/feature_dictionary.md`（记录每个特征的中文定义、计算逻辑与重要性）；
3. **周报总结与 GitHub 同步**: 提交第二周详细周报并推送全部代码至 GitHub。
