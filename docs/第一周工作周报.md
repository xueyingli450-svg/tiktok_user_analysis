## 一、 本周具体工作内容与进展

本周我主要按计划完成了以下几项具体工作：
### 1. 开发环境搭建与数据初探 (Day 1)
- 按照编码规范建立了标准的项目目录结构，分为 `src/`（代码）、`data/`（数据）、`docs/`（文档图表）、`tests/`（测试）；
- 配置了 Python 3.12 虚拟环境并记录了 `requirements.txt`；
- 在代码中统一使用 `pathlib.Path` 配置了**相对路径**读取数据，避免了绝对路径写死的问题；
- 编写了初探脚本 `inspect_data.py` 读取前 10 行数据进行验证，确认了原始 CSV 带有表头，并理清了字段的实际顺序（`time, user_id, item_id, item_category, behavior_type`）。

### 2. 海量数据清洗与异常处理 (Day 2)
编写并执行了清洗脚本 `clean_data.py`，处理了全部 1225 万条原始数据：
- **空值与异常行为过滤**: 剔除缺失值，并将 `behavior_type` 严格限制在 1~4（浏览、收藏、加购、购买）范围内；
- **时间拆分**: 将时间字段解析并拆分出 `date`（日期）和 `hour`（小时）两列，方便后续按时间分析；
- **四元组去重**: 基于“用户-商品-行为-时间”四元组去重，剔除了 6,043,527 条重复记录；
- **IQR 爬虫过滤**: 采用 IQR 四分位距法（阈值设为 $Q_3 + 3 \times IQR = 2658$ 次），排查并剔除了 269 个高频异常爬虫账号（共 1,024,887 条异常记录）；
- **数据保存**: 最终留存 5,188,492 条干净数据，转存为 Parquet 格式，并自动输出了数据清洗质量报告（`docs/data_quality_report.md`）。

### 3. SQLite 数据库搭建与批量入库 (Day 3)
- 编写建表脚本 `create_tables.sql`，创建了 `user_behavior` 数据表，并针对高频查询字段建立了 4 个索引（`idx_user_time`, `idx_behavior_type`, `idx_date_hour`, `idx_item_category`）以提升查询速度；
- 封装了通用的数据库连接模块 `src/utils/db_connector.py`；
- 编写入库脚本 `load_to_sqlite.py`，将 518 万条 Parquet 数据批量导入到 `data/ecommerce.db` 中，并验证了数据库实际行数与源数据完全一致（5,188,492 行）；
- 将代码同步推送到 GitHub 公开仓库，并补充了 `README.md` 项目说明。

### 4. SQL 业务指标分析与 Python 绘图 (Day 4)
- 编写了 3 个独立的 SQL 分析脚本（`basic_metrics.sql`、`time_distribution.sql`、`funnel_analysis.sql`），分别计算大盘指标、时间分布和转化漏斗；
- 编写 Python 绘图脚本 `eda_analysis.py`，读取 SQLite 数据并绘制了 4 张分析图表（保存在 `docs/figures/` 目录下）：
  1. `fig1_hourly_activity.png`：24小时活跃与购买走势折线图；
  2. `fig2_daily_dau_trend.png`：每日 DAU 活跃趋势柱状图；
  3. `fig3_behavior_distribution.png`：四类行为占比环形图；
  4. `fig4_conversion_funnel.png`：全链路转化漏斗图；
- 自动生成了业务洞察记录 `docs/eda_findings.md`。

### 5. 代码规范整理与周报总结 (Day 5)

## 二、 核心数据结果与业务发现

### 1. 数据清洗统计结果
- **原始数据量**: 12,256,906 行
- **剔除重复记录**: 6,043,527 行
- **剔除爬虫异常记录**: 1,024,887 行（涉及 269 个账号）
- **清洗后有效数据量**: 5,188,492 行（留存率 42.33%）
- **覆盖独立用户数 (UV)**: 9,731 人
- **人均浏览次数**: 474.77 次/人

### 2. 初步业务发现
1. **活跃时段分布**: 用户的活跃度从早上 8 点开始逐渐上升，午间 13:00 有一个小高峰；**全天最高峰集中在晚间 20:00 - 22:00**（下单量超过 700 单/小时），之后逐渐回落；
2. **大促活动影响**: 日常日活（DAU）稳定在 6000~6500 人左右，但在 **12 月 12 日（双十二当天）DAU 明显上涨到了 7,455 人**，且大促前两天有小幅增长趋势；
3. **行为结构特征**: 整个行为数据中，浏览（PV）占 89.04%，**加购占比（5.46%）高于收藏（3.63%）**，购买占比 1.87%；
4. **转化漏斗表现**: 在 30 天周期内，9,731 名用户中有 93.06% 产生过加购或收藏行为，88.60% 的用户完成过至少一次购买。
